# Travel Site

Frontend white label para venda de passagens fluviais, feito com Vue.js, Vite e Tailwind CSS.

## Tecnologias

- Vue 3
- Vite
- Tailwind CSS
- Vue Router
- Lucide Icons

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Variaveis de ambiente

Crie um arquivo `.env` com base no `.env.example`:

```bash
VITE_API_BASE_URL=http://localhost:8001
```

O arquivo `.env` nao deve ser enviado para o Git.
